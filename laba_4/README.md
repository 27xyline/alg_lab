# Лабораторная работа № 4

Корреляционный и регрессионный анализ трёх наборов данных из задания.

## Запуск

Из корня проекта:

```bash
uv run laba_4/main.py
```

Программа выводит результаты в терминал и сохраняет графики в `laba_4/results/`.

## Метод

Для пар наблюдений вычисляются средние `x̄`, `ȳ`, суммы `Sxx = Σ(xᵢ − x̄)²`, `Syy = Σ(yᵢ − ȳ)²` и `Sxy = Σ(xᵢ − x̄)(yᵢ − ȳ)`. Ковариация и средние квадратические отклонения рассчитаны с делением на число наблюдений `n`: `cov = Sxy/n`, `σx = √(Sxx/n)`, `σy = √(Syy/n)`. При делении на `n − 1` их значения отличаются, но коэффициент корреляции остаётся тем же.

Коэффициент Пирсона `r = Sxy / √(Sxx·Syy)`. Для линейной модели с константой `ŷ = ax + b` метод наименьших квадратов даёт `a = Sxy/Sxx`, `b = ȳ − ax̄`. Коэффициент детерминации для такой модели равен `R² = r²`.

## Результаты

### 1. Содержание компонента и твёрдость

- Ковариация: **5,0793**; СКО X: **1,1034**; СКО Y: **6,1934**.
- `r = 0,7433`: заметная положительная линейная связь; при большем содержании компонента твёрдость в среднем выше.
- Модель: **ŷ = 4,1720x + 31,7817**.
- `R² = 0,5524`: модель объясняет около **55,24%** изменчивости твёрдости. Линейная модель отражает тенденцию, но оставляет существенную часть разброса необъяснённой.
- Корреляционное поле и прямая регрессии: [task1.png](results/task1.png).

### 2. Расходы на рекламу и доход

- `r = 0,8916`: сильная положительная линейная связь.
- Модель: **ŷ = 0,5774x + 30,9996**, где X — тыс. руб., Y — млн руб.; `R² = 0,7949`.
- При расходах **40 тыс. руб.** прогноз дохода — **54,09 млн руб.**
- Подставляя 70 в уравнение и решая его относительно X, получаем **67,55 тыс. руб.** Это экстраполяция за пределы наблюдавшихся расходов 18–54 тыс. руб., поэтому оценка менее надёжна.
- График: [task2.png](results/task2.png). Корреляция сама по себе не доказывает, что расходы вызвали рост дохода.

### 3. Численность размещённых туристов

- Модель по данным 2011–2021 годов: **ŷ = 1855,4818 × период + 10 312,3818**, Y измеряется в тыс. человек. Период 1 соответствует 2011 году, период 11 — 2021 году, период 12 — 2022 году.
- `R² = 0,9317`: линейный тренд объясняет около **93,17%** изменчивости наблюдений в 2011–2021 годах.
- Прогноз на 2022 год: **32 578,16 тыс. человек**; фактическое значение по условию — **29 547 тыс. человек**.
- Относительная погрешность: `|32578,16 − 29547| / 29547 × 100% =` **10,26%**.
