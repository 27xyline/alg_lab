# Лабораторная работа № 3

Численное решение задачи о полёте снаряда методом Рунге — Кутты четвёртого порядка.

## Постановка и исходные данные

Рассматривается движение в вертикальной плоскости. `x1` и `x2` — горизонтальная координата и высота; `v1` и `v2` — соответствующие составляющие скорости. Система:

```text
dx1/dt = v1
dx2/dt = v2
dv1/dt = -k * sqrt(v1² + v2²) * v1
dv2/dt = -k * sqrt(v1² + v2²) * v2 - g
```

Начальные координаты равны нулю, начальная скорость — 1000 м/с, угол — 45°. Поэтому начальные скорости по осям равны `1000 * cos(45°)` и `1000 * sin(45°)` м/с.

Плотность воздуха — 1,2041 кг/м³, коэффициент аэродинамического сопротивления — 0,47, плотность чугуна — 7200 кг/м³, диаметр снаряда — 0,1 м. Принято `g = 9,81 м/с²`.

В задании форма снаряда не указана. Для расчёта массы предполагается, что снаряд — однородный шар. Тогда `S = πd²/4`, `m = ρ_чπd³/6`, а коэффициент сопротивления `k = CρS/(2m) ≈ 0,00058951 м⁻¹`. Форму снаряда стоит сверить с примером из лекции № 4.

## Метод и результаты

Функция `rk4_step` выполняет один шаг метода для вектора состояния `y = (x1, x2, v1, v2)`. В этой задаче правые части системы `F(y)` не зависят от времени напрямую:

```text
k1 = F(y)
k2 = F(y + h*k1/2)
k3 = F(y + h*k2/2)
k4 = F(y + h*k3)
y_след = y + h*(k1 + 2*k2 + 2*k3 + k4)/6
```

Моделирование продолжается до пересечения высоты `x2 = 0` после взлёта. Положение и время падения определяются линейной интерполяцией между последними двумя точками; максимальная высота берётся среди сохранённых точек, то есть является приближённой.

Расчёт выполнен с шагом 0,5 с в обоих случаях. В задании этот шаг указан для случая без сопротивления; для случая с сопротивлением он принят таким же.

| Результат | Без сопротивления | С сопротивлением |
| --- | ---: | ---: |
| Время полёта, с | 144,16 | 41,08 |
| Дальность, м | 101 936,53 | 4 012,62 |
| Максимальная высота, м | 25 484,17 | 2 167,34 |

Результат без сопротивления был проверен сравнением с аналитическим решением. Для случая с сопротивлением также были сравнены результаты с шагами 0,5 и 0,25 с.

## Объяснение для защиты

### Что делает программа

Программа рассчитывает полёт снаряда в вертикальной плоскости от выстрела до падения на землю. Расчёт выполняется два раза: сначала без сопротивления воздуха, затем с сопротивлением. По полученным точкам строятся три графика.

В любой момент снаряд описывается четырьмя величинами:

- `x1` — расстояние по горизонтали;
- `x2` — высота над землёй;
- `v1` — горизонтальная составляющая скорости;
- `v2` — вертикальная составляющая скорости.

В программе эти величины вместе хранятся в `state` в порядке `(x1, x2, v1, v2)`. Для каждой точки полёта также сохраняется время: `(t, x1, x2, v1, v2)`.

### Что означают уравнения

Первые два уравнения говорят, что скорость изменения координаты равна соответствующей составляющей скорости: `dx1/dt = v1`, `dx2/dt = v2`.

Два других уравнения описывают изменение скоростей. Выражение `sqrt(v1² + v2²)` — полная скорость снаряда. Слагаемые с `k` описывают сопротивление воздуха, направленное против скорости; `-g` в уравнении для `v2` учитывает действие силы тяжести.

Функция `derivatives(state, drag)` вычисляет правые части всех четырёх уравнений для текущего состояния. Здесь `drag` — коэффициент сопротивления `k` из условия. Полная скорость вычисляется с помощью `math.hypot(vx, vy)`.

При выстреле координаты равны нулю. Начальная скорость 1000 м/с раскладывается на горизонтальную и вертикальную составляющие с помощью косинуса и синуса угла. При 45° обе составляющие примерно равны 707,1 м/с.

### Как работает метод Рунге — Кутты

Метод позволяет по известному состоянию снаряда вычислить приближённое состояние через небольшой промежуток времени `h`. В программе один такой шаг выполняет функция `rk4_step`.

На каждом шаге производные вычисляются четыре раза:

1. `k1` — в начале шага;
2. `k2` — в середине шага, используя оценку `k1`;
3. `k3` — ещё раз в середине, используя оценку `k2`;
4. `k4` — в конце шага, используя оценку `k3`.

Затем эти оценки объединяются с весами **1, 2, 2, 1**, как показано в формулах выше. Так вычисляются новые значения сразу для обеих координат и обеих скоростей. В коде `zip` сопоставляет каждую величину состояния с соответствующей ей производной.

Здесь `k1`, `k2`, `k3`, `k4` — оценки производных метода Рунге — Кутты. Их не нужно путать с коэффициентом сопротивления воздуха `k`. В методичке приращения уже умножены на шаг `h`; в программе оценки производных умножаются на `step` отдельно. Формулы эквивалентны.

### Как определяется падение

Функция `simulate_flight` повторяет шаги расчёта, пока следующая высота `x2` не станет нулевой или отрицательной. Начальная высота тоже равна нулю, но проверка выполняется после вычисления следующего состояния, поэтому в начале полёта программа не останавливается.

При фиксированном шаге точка падения обычно находится между последней точкой над землёй и следующей точкой под землёй. Программа приближённо находит время и координаты падения **линейной интерполяцией** между ними. Например, если высоты соседних точек равны 10 м и −10 м, падение оценивается посередине шага. Поэтому найденная конечная точка приблизительная.

### Чем отличаются два случая

- **Без сопротивления:** `k = 0`. Горизонтальная скорость постоянна, а вертикальная уменьшается из-за силы тяжести. Траектория представляет собой параболу.
- **С сопротивлением:** `k = CρS/(2m)`. Воздух тормозит снаряд, поэтому в данном расчёте он достигает меньшей высоты и пролетает меньшее расстояние.

Для вычисления массы снаряд принят **однородным шаром**, потому что в задании указаны плотность и диаметр, но не форма. Это допущение нужно сверить с примером из лекции № 4. Ускорение свободного падения принято равным 9,81 м/с². Шаг 0,5 с в задании явно указан для случая без сопротивления; для второго случая он принят таким же.

### Какие графики построены

- `x1_of_t.svg` — горизонтальная координата от времени `x1(t)`;
- `x2_of_t.svg` — высота от времени `x2(t)`;
- `trajectory.svg` — траектория полёта `x2(x1)`.

На каждом рисунке слева показан расчёт без сопротивления, справа — с сопротивлением. **Масштабы осей разные**: расстояния и высоты сильно отличаются, поэтому при сравнении нужно смотреть на значения на осях. Графики сохраняются в папке `results` и открываются в браузере.

### Как проверен результат

Без сопротивления дальность для выстрела и падения на одной высоте можно вычислить по формуле `L = v0² sin(2α) / g`. При `v0 = 1000 м/с`, `α = 45°` и `g = 9,81 м/с²` получается примерно **101 936,80 м**. Программа даёт **101 936,53 м**. Разница около 0,27 м в основном связана с приближённым определением точки падения между шагами.

Для случая с сопротивлением сравнивались результаты при разных шагах: при `h = 0,5 с` дальность составила **4012,62 м**, а при `h = 0,25 с` — **4012,80 м**. Близость результатов показывает, что уменьшение шага в этом случае мало меняет рассчитанную дальность, хотя само по себе не доказывает точность модели.

Вывод: согласно принятой модели, сопротивление воздуха значительно уменьшает высоту и дальность полёта. Численные значения зависят от исходных данных и допущения о форме снаряда.
